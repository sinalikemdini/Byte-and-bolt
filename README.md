My program is a Python-based code for the Byte and Bolt tech hire.
Make sure you have tkinter, tkcalendar, and Pillow(PIL) installed on your computer, or it will show an error.
Also make sure the Logo.png  is in the same folder as the code or else an error will occur and the code will not run(crashes).
Also make sure the json file is also in the file or the code will generate a new json file.

Required Libraries
To Install tkcalendar --> pip install tkcalendar(Used for the hire date calendar picker).
To install Pillow(PIL) --> pip install pillow(Used for the images(logo) to display).**
Note: random does not need to be installed because it is already included with Python.

Instructions on how to use the program:
1.Go to the home screen and from there you can navigate into add hire window through the home page or the sidebar if you want to hire an item.
2.In add hire window enter your name, select an item by pressing the "select item" button on the add hire window. In the item selection window select an item and confirm to return to the add hire window again.
3. Then select the quantity and then select the date by pressing the calendar button and select a date and confirm.
4. Then press the "Confirm Selection" button. If all the entered information is valid, the program will automatically generate a unique random 6-digit receipt number and display a receipt with all the hire details. Press the Home button on the receipt window to return to the home screen.
If you want to hire another item under the same customer name, press the "X" on the receipt window instead of pressing Home. This will return you to the Add Hire window with the previous details still there, so you do not need to enter everything again. You can change the item, quantity or date if needed and press "Confirm Selection" again. A new unique 6-digit receipt number will be generated for the next hire.
5. If you want to view the current hires go to it by pressing the current hires button on the home screen or the sidebar.
6. Then there you can scroll down and find your hire or you can search it in the search bar by the person's name, press confirm and get the hire.
7. Do delete the record select the record and press the delete record button so the record will be deleted from the file. Then you can again go back to the home screen by pressing the Home button.
8. If you want to exit the program you can just press the exit button or press the "X" at the top right corner of the interface.

Hope this helps.
